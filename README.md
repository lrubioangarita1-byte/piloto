# piloto

Automatización de facturación y auditoría para la UCI Neonatal: validación de RIPS, alertas de historias clínicas incompletas e indicadores de calidad, apoyada en un mini PC local conectado de solo lectura al HIS (Siscolsi).

Reglas de seguridad no negociables y contexto operativo: ver [`CLAUDE.md`](./CLAUDE.md).

Plan de fases completo: ver [`docs/plan.md`](./docs/plan.md).
